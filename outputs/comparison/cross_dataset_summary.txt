============================================================

  IQ-OTH/NCCD — Iraqi-Oncology-Teaching-Hospital / NCI dataset
              — Clean, well-structured CT scan images
  LIDC-IDRI   — Lung Image Database Consortium
              — Larger, more diverse, community-annotated

Models compared: EfficientNet-B0, DenseNet-121, ResNet-50, Ensemble

Results (Accuracy / ROC AUC):

  Ensemble (XGBoost)     IQ-OTH: 98.8% / 100.0%  |  LIDC: 84.0% / 92.2%

Interpretation:
  - If LIDC-IDRI accuracy is lower, it confirms better generalisation
    challenge — the model is not over-fitting to one dataset.
  - The Ensemble should outperform individual models on both datasets.
  - If IQ-OTH scores are still near-perfect, consider increasing
    regularisation or using cross-dataset validation.
