## Fixes Applied Before Retraining

### Fix 1 — Data Leakage in Ensemble (train_ensemble.py)

**Problem**: XGBoost meta-learner was trained using base model predictions
on the training set — the same data the base models were trained on.
Because the models achieved near-zero training loss (e.g. ResNet loss = 0.0011),
their training-set predictions were perfect, giving XGBoost trivially perfect
features. This caused all metrics to appear as 100%.

**Fix**: Meta-learner now trains on base model predictions from the
**validation set** (164 images the base models have never seen).
This gives honest, leakage-free meta-features.

### Fix 2 — GAN Not Integrated (run_gan_augmentation.py)

**Problem**: The Conditional GAN code existed but was only used in a demo
script that ran on random dummy images. `train.py` had no GAN calls at all,
and `GAN_ENABLED = True` in config was never read.

**Fix**: Created `run_gan_augmentation.py` which:
1. Trains the GAN on **real CT images** from the training folder
2. Generates synthetic images for the minority class
3. Resizes them from 64×64 → 224×224
4. Saves them directly into the training folder with a `synthetic_` prefix
5. Must be run before `train.py` so base models train on augmented data

## Training Order (Kaggle)

```bash
# ── Dataset 1: IQ-OTH/NCCD ──────────────────────────────────────────────
python prepare_kaggle_dataset.py                         # download + organise

python run_gan_augmentation.py --epochs 150              # GAN augmentation

python train.py --model efficientnet --epochs 50 --data-dir data/kaggle_lung_cancer
python train.py --model densenet     --epochs 50 --data-dir data/kaggle_lung_cancer
python train.py --model resnet       --epochs 50 --data-dir data/kaggle_lung_cancer

python train_ensemble.py                                 # uses val set (no leakage)

# ── Dataset 2: LIDC-IDRI ────────────────────────────────────────────────
# On Kaggle: add LIDC-IDRI as an input dataset, then:
python prepare_lidc_dataset.py --source-dir /kaggle/input/<lidc-slug>

python run_gan_augmentation.py \
    --data-dir data/lidc_idri/train --epochs 150

python train.py --model efficientnet --epochs 50 \
    --data-dir data/lidc_idri \
    --checkpoint-dir checkpoints/lidc_idri \
    --output-dir outputs/lidc_idri
python train.py --model densenet --epochs 50 \
    --data-dir data/lidc_idri \
    --checkpoint-dir checkpoints/lidc_idri \
    --output-dir outputs/lidc_idri
python train.py --model resnet --epochs 50 \
    --data-dir data/lidc_idri \
    --checkpoint-dir checkpoints/lidc_idri \
    --output-dir outputs/lidc_idri

python train_ensemble.py \
    --val-dir  data/lidc_idri/val \
    --test-dir data/lidc_idri/test \
    --checkpoint-dir checkpoints/lidc_idri \
    --output-dir outputs/lidc_idri

# ── Compare both datasets ────────────────────────────────────────────────
python compare_datasets.py                               # generates comparison plots + CSV

# ── Grad-CAM ─────────────────────────────────────────────────────────────
python generate_gradcam.py
```
